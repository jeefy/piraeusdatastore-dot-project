# Security Policy

## Reporting Security Issues

The Piraeus Datastore maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/piraeusdatastore/piraeus-operator/security/advisories/new) form.

For more details, see the [Piraeus Datastore security policy](https://github.com/piraeusdatastore/piraeus-operator/blob/v2/SECURITY.md).
